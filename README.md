# Care.All Web Project

  Repositório do projeto acadêmico de desenvolvimento web da empresa fictícia Care.All, utilizando HTML, CSS e JavaScript.

  O projeto foi criado como parte da disciplina de Programação para Internet, com foco na construção de uma plataforma social, responsiva, acessível e interativa.

## Sobre o projeto

  A Care.All é uma startup fictícia de impacto social criada com o objetivo de auxiliar pacientes e acompanhantes vindos do interior em busca de tratamento médico na Região Metropolitana do Recife (RMR).

  A plataforma busca conectar essas pessoas a hospedagens acessíveis ou gratuitas próximas aos centros de tratamento, utilizando a tecnologia como ferramenta de acolhimento, acessibilidade e suporte social.

  Além das hospedagens, o projeto também apresenta iniciativas voltadas ao apoio emocional, transporte solidário, orientação ao paciente, programas sociais e participação de voluntários.


## Funcionalidades

### Estrutura 
- Header fixo.
- Menu hambúrguer responsivo e animado.
- Footer estruturado.
- Hero section da página principal com animação de digitação.
- Sistema de navegação entre páginas.
- Menu ativo conforme a página atual.
- Organização semântica com HTML5.


### Seções Implementadas
- Seção inicial (home).
- Seção Sobre. 
- Seção Hospedagens.
- Seção Projetos.
- Seção Contato.

### Interatividade e UX
- Menu hambúrguer com abertura e fechamento.
- Dark/Light mode toggle com persistência usando localStorage.
- Cards com efeitos hover.
- Modais interativos.
- Filtros/abas de projetos.
- Transições e animações CSS com @keyframes.
- Scroll suave.
- Menu ativo por página.

### Responsividade
- Layout adaptado para diferentes tamanhos de tela.
- Uso de Flexbox, CSS Grid, clamp(), max-width, porcentagens e media queries.
- Ajustes específicos para telas mobile.
- Testes visuais realizados em diferentes larguras de tela.

### Performance

- Projeto desenvolvido com HTML, CSS e JavaScript puro.
- Sem uso de frameworks externos pesados.
- Validação de performance realizada com Lighthouse.

## Tecnologias utilizadas
